# Les gens de la maison

Une section par personne, au prénom que le robot a enregistré pour sa voix. Lignes courtes, en français.

## Exemple
- Prénom : Exemple. Tutoiement.
- Dates : anniversaire le 1er janvier.
- Goûts : aime le jazz, déteste la coriandre.
- Habitudes : télétravail le lundi.

## Règles
- Rien n'est noté sur les invités.
- La section « Exemple » peut être supprimée dès qu'une vraie personne est notée.
